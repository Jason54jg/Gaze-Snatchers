Install

Dual-loader: pick Fabric or NeoForge for your instance.

Supported versions

  • 1.21.11 (default profile, JDK 21)
  • 26.1.2 / 26.2 / 26.3 (JDK 25)

Players (ready JAR)

Download from Modrinth (page may be empty until the first release is published).

  1. Install Fabric or NeoForge for your Minecraft version.
  2. Get the matching JAR from modrinth.com/project/gaze-snatcher.
  3. Drop the JAR into mods/.
  4. Launch the game. Config appears at config/gazesnatchers.json.

Build from source

Current profile (1.21.11):

./gradlew build

Full matrix (Windows, PowerShell):

$env:JAVA_HOME = "C:\Program Files\Java\jdk-25.0.3"
$env:BUILD_26 = "true"
.\scripts\build-all-versions.ps1

JARs are written under release/<minecraft_version>/.

Dev client

./gradlew :fabric:runClient
./gradlew :neoforge:runClient

Dependencies

  • GeckoLib — required on Fabric and NeoForge (match your Minecraft version).
  • Fabric API — required on Fabric only.

Prefer published JARs from Modrinth so dependency versions stay aligned. English listing / changelog copy for publishers: docs/MODRINTH.md.
