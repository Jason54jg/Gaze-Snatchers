Installation

Dual-loader : choisissez Fabric ou NeoForge selon votre instance.

Versions supportées

  • 1.21.11 (profil par défaut, JDK 21)
  • 26.1 / 26.1.1 / 26.1.2 / 26.2 / 26.3 (JDK 25)

Joueur (JAR prêt)

  1. Installez Fabric ou NeoForge pour votre version de Minecraft.
  2. Téléchargez le JAR correspondant depuis les releases GitHub (dossier release/<version>/ dans le dépôt).
  3. Placez le JAR dans le dossier mods/.
  4. Lancez le jeu. La config apparaît dans config/gazesnatchers.json.

Build depuis les sources

Profil courant (1.21.11) :

./gradlew build

Toute la matrice (Windows, PowerShell) :

$env:JAVA_HOME = "C:\Program Files\Java\jdk-25.0.3"
$env:BUILD_26 = "true"
.\scripts\build-all-versions.ps1

JARs générés sous release/<minecraft_version>/.

Dev client

./gradlew :fabric:runClient
./gradlew :neoforge:runClient

Dépendances

Le mod s’appuie notamment sur Architectury et GeckoLib (versions gérées par le build Gradle). Utilisez les JARs publiés pour éviter les conflits de versions.
